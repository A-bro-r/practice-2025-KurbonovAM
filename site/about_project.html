Группа проектов "Робостанция"

Подпроект: Дрон Лига

Главная О проекте Участники Журнал Ресурсы

О проекте

Цель проекта: формирование цифрового и инженерного сознания молодёжи через игровые образовательные технологии.

Задачи проекта
Разработать два уровня сложности дронов:
• Базовый (Level 1) — управление по радио, без программирования (для 12–14 лет);
• Продвинутый (Level 2+) — программирование на C++, автономная навигация (для 15–18 лет).
Создать минимум 3 сценария соревнований:
• "Гонка по кругу" — скорость и маневренность;
• "Поиск и спасение" — распознавание цветовых меток + доставка груза;
• "Эстафета команд" — кооперативное управление 2+ дронами.
