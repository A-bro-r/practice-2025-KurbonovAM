### Введение в проблему
Судоку — это логическая головоломка, цель которой заполнить сетку 9×9 цифрами от 1 до 9 так, чтобы в каждом столбце, каждой строке и каждом из девяти блоков 3×3 каждая цифра встречалась только один раз. Создание программы для её решения — классическая задача для изучения алгоритмов и структур данных.

Проект `C: sudoku solver` представляет собой пошаговое руководство по созданию «эвристического» решателя судоку на языке C, разбитое на 8 логических этапов. Это отличная отправная точка для новичков, желающих понять, как «думает» программа, решающая логические задачи.

### Исследование предметной области и выбор технологии

#### Почему C и эвристика, а не Python и backtracking?
Выбор языка C в учебном проекте позволяет глубже понять управление памятью и структурами данных в противовес высокоуровневому Python, где многие детали скрыты.

Выбор эвристического подхода вместо рекурсивного перебора (backtracking) также продиктован педагогическими целями:
*   **Backtracking-алгоритм**  — это универсальный, но «слепой» метод проб и ошибок. Он гарантирует решение, но не дает понимания логики головоломки.
*   **Эвристический подход** имитирует рассуждения человека: программа на каждом шаге ищет клетки, для которых возможна только одна цифра, и заполняет их, постепенно упрощая задачу. Этот процесс более нагляден и понятен.

### Техническое руководство: Создаем свой решатель судоку на C

В этом руководстве мы шаг за шагом воссоздадим логику проекта `C: sudoku solver`, написав простой, но эффективный решатель судоку. Мы будем использовать язык C и компилятор `gcc`.

#### Этап 1: Определение основных структур данных
Основа нашего решателя — три ключевые структуры, описанные в заголовочном файле `sudoku.h`.

*   **`Square` (Клетка):** Представляет одну ячейку поля. Хранит её `number`, `row`, `column`, массив `possible` для 9 цифр (1 — кандидат, 0 — исключен) и флаг `solvable` (количество оставшихся кандидатов). Указатель `box` связывает клетку с её блоком 3×3.
*   **`Box` (Блок):** Представляет блок 3×3. Содержит массив из 9 клеток, счетчик `numbers` (сколько цифр уже определено) и массив `possible` для учета кандидатов в рамках блока.
*   **`Sudoku`:** Верхнеуровневая структура, объединяющая двумерный массив `squares` и массив `boxes`.

```c
// Фрагмент из sudoku.h
typedef struct Square {
    int number;
    int possible[9];
    int solvable;
    Box * box;
    int row;
    int column;
} Square;

typedef struct Box {
    struct Square ** squares;
    int numbers;
    int possible[9];
    int solvable;
    struct Box * next;
} Box;

typedef struct Sudoku {
    struct Square *** squares;
    struct Box ** boxes;
} Sudoku;
```

#### Этап 2: Инициализация и загрузка пазла
На этом этапе мы создаем каркас будущей игры с помощью функции `createPuzzle()`.

1.  **Выделяем память:** С помощью `malloc` создаем двумерный массив `int ** puzzle` размером 9×9.
2.  **Заполняем нулями:** Все клетки изначально пустые (`0`).
3.  **Добавляем известные числа:** Вручную или из файла заполняем нужные ячейки, создавая условие задачи.

После создания числовой матрицы мы формируем полноценную структуру `Sudoku` с помощью `setUpPuzzle()`.

#### Этап 3: Разработка эвристического алгоритма
Сердце программы — функция `checkPuzzle()`. Она запускается в цикле, который продолжается, пока счетчик нерешенных клеток `UNSOLVED` больше нуля.

На каждой итерации алгоритм выполняет три проверки для каждой пустой клетки `Square` и связанного с ней блока `Box`:
1.  **Проверка блока (`boxSingles`):** Для каждого блока 3×3 мы анализируем, какие цифры еще не встречаются. Если какая-то цифра может быть поставлена только в одну клетку блока, мы ее туда записываем.
2.  **Проверка строк и столбцов (`checkRows`):** Аналогичная логика, но применяется к каждой строке и каждому столбцу.
3.  **Проверка клетки (`solveSquare`):** Для каждой клетки мы собираем кандидатов, исключая цифры, уже присутствующие в ее строке, столбце и блоке. Если остается только один кандидат, клетка решена.

```c
// Упрощенная логика из sudoku.c (Tutorial 8 end)
while (UNSOLVED > 0) {
    progress = checkPuzzle(sudoku->squares, sudoku->boxes);
    if (progress == 0) {
        printf("\nFailed to solve the puzzle!\n\n");
        break;
    }
}
```

#### Этап 4: Компиляция и запуск программы
Для сборки проекта используется `makefile`. Финальная версия проекта компилируется и запускается следующим образом:

```bash
make
./sudoku
```

На экран будет выведено исходное состояние пазла, а затем — решенное.
